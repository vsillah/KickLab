# Race Quick Challenge v1

PR #68 established an opt-in, same-device alternating match in memory. It freezes Race mode, vehicle, Garage tune, venue, steering, and numeric parameters; intercepts a finish before solo awards; and scrubs replay at profile handoff. PR #69 added Championship as a separate device-local progression lane. Quick Challenge uses the same match state and finish interception, but transfers the first run through a private text code. It never enters Championship results or solo progress.

The `raceMultiplayer=prototype` and `raceExpansion=prototype` flags on a trusted origin expose the menu. Couch Duel remains the local two-profile mode. Quick Challenge has a creator and challenger flow. Live Room is disabled and names the later protected service phase. No service is contacted by this feature.

`KLQ1` codes contain version, kind, an explicitly entered alias, the canonical mode/vehicle/Garage/venue/steering/target contract, a bounded result, and up to 96 sampled ghost poses. Pose samples are time, x, y, heading, and course progress, drawn from the existing Race recording. The decoder caps input at 12,000 characters and JSON at 8,500 UTF-8 bytes, validates enumerations and finite ranges, checks monotonic sample time, and verifies a damage checksum. It rebuilds accepted fields before applying a contract. The checksum detects corruption; it does not authenticate a person or prevent a determined sender from forging a self-reported result. Imported text enters the interface with `textContent`.

The challenger sees an interpolated, translucent copy of the canonical 3D vehicle at the recorded poses. This is sampled playback of a completed run, not a physics simulation of another player. Canvas fallback retains text progress without inventing a schematic 3D substitute. The challenger generates a small response code with the challenge checksum and result. The creator must keep the original tab open and paste that response there to compare; nothing is stored remotely or in profile progress.

The exchange is private only to the extent that players share codes privately. It contains no account ID, profile ID, nickname, contact, telemetry log, chat, or full replay recording. The player can leave a challenge to clear the in-memory match and restore their local Garage setup. A profile switch also clears the challenge. Authentication, connected rooms, invitations, uploads, public boards, analytics, and providers remain outside this phase.
