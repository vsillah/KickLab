## Compatibility and privacy

The original profile IDs (`rocket`, `wiz`, `tower`, `trick`, `cannon`) remain the portrait mapping contract. `avatarLook` is still normalized and saved, including the combinations created by PR #111's first draft; it is never deleted or rewritten on nickname-only edits. The curated portrait is selected deterministically by the stable profile ID. Selecting another curated driver updates the ID and its canonical stored look. Reset selects Rocket. This trades combinatorial appearance options for five coherent, readable game portraits while retaining prior data for a future compatible editor.

The Coach's Race profile portrait uses the new local five-expression sheet at its ready frame, with initials as a load fallback. The four Coach sheets were regenerated in the same art direction; see [Race Coach portrait art, v2](race-coach-art-v2.md). Coach identity, selection, and default-off flag behavior are unchanged. Couch Duel renders the two local profiles; Vs Computer uses a labeled initials fallback. Quick Challenge and Private Party show a local driver portrait and text/initials for the remote alias. No portrait data is placed in a challenge code or sent across devices.

No photo upload, camera capture, face recognition, biometric inference, EXIF processing, external runtime generation, account, provider, or sharing route was added. Photo support remains deferred pending child-safety consent, retention, and sharing decisions.
