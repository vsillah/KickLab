## Qualification stop

The Simulator app can be observed, rotated, installed, and launched, but its Computer Use coordinate click returns `Computer Use server error -10005: noWindowsAvailable` on repeated attempts. AX exposes Simulator chrome but not WKWebView controls. A keyboard Tab did not establish visible in-app focus. A window-level AX click inadvertently opened Race in landscape, confirming some input delivery, but it did not give a reliable way to select and exercise the required Fight control gate. The current Fight fix therefore remains **unverified**, not failed.

Do not treat the earlier missing-control screenshots as a present defect, and do not treat this checkpoint as native qualification. The smallest remaining gate is reliable native touch/AX interaction for live Fight on this rebuilt binary; after that, iPhone/iPad portrait/landscape Fight, Race, and Kick journeys, genuine native damage, live storage recovery/deletion/migration, VoiceOver, native reduced-motion behavior, offline transitions, physical-device performance and thermal behavior, final privacy/permission declarations, and continuous all-state egress trace remain open. Resume only with reliable Simulator touch/AX interaction against this exact package or a newly rebound package.
