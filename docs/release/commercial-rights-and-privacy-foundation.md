## Commercial scope and exact package

V1 is paid upfront, local first, ages 9–15, with Fight, Race and Kick; Race is the hero. The approved exclusions are ads, IAP, accounts, chat, uploads, analytics, public matchmaking, public leaderboards, cloud sync, camera scanning, OS Share, Race file Download, and spoken Coach audio. Private Party remains offline QR display and manual paste. These are release requirements to verify against each exact artifact, not a claim that static inspection alone proves every runtime path.

The freshly built [shipped-file ledger](shipped-file-rights.csv) maps all **236** mobile paths to their SHA-256, size, source or generator, owner claim, use basis, attribution, evidence, and disposition. It retains **211 held rows**, **23 source/provenance files marked for exclusion**, and **two build metadata rows needing exclusion or necessity review**. The [17-group action register](rights-owner-action-groups.md) assigns all 236 exact paths to owner actions; 209 holds are runtime candidates and two MakeHuman source/provenance holds are proposed for exclusion. A manifest or artist note establishes a claim, not chain of title. The source for `index.html` contains imported v42 code and embedded Fight/Kick content; no signed owner assignment and complete redistribution record was found in this repository. The entire commercial release stays on hold until that is resolved.

The [runtime dependency ledger](runtime-dependencies.csv) maps **128** non-root lockfile packages: five production-tree entries, one embedded-runtime/build entry, and 122 build-only entries. Three.js 0.186.1 is embedded in the HTML bundle and `qrcode-generator` 1.5.2 is copied as `party-qr.js`; both are MIT, requiring copyright and permission notices in the final distribution. Capacitor Core/App/Haptics are MIT and `tslib` is 0BSD per pinned local package evidence, but actual native inclusion is unverified. The [draft distribution notice bundle](distribution-notices-draft.md) copies supported license texts and flags the missing upstream QR license file and native transitive audit. The freshly prepared `dist/mobile` contains **no separate license or notice file**. `npm audit --omit=dev` reported zero production-tree findings at this check time; that is not license or native security clearance.
