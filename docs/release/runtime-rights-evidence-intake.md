Use the [209-row exact-file plan](runtime-rights-evidence-plan.csv) as the intake queue. It is bound to the 210-file package at merged main `2140e0cf0c3d74845a7e384aa8200a46cde9115f`. ## Intake for each path

- [ ] Match relative path, SHA-256, bytes, rights group, and candidate commit to the shipped ledger. Reject duplicates or a stale/rebuilt file.
- [ ] Confirm the actual product consumer and visible surface. For the 11 packaged-only candidates, inspect default, prototype, fallback, and offline paths before claiming no live consumer.
- [ ] Identify all creators and contributors; collect signed assignment, license, or original-author evidence that permits paid redistribution. Record dates and terms in force when each input was made.
- [ ] Trace generator/script, editable source, export command, input files, output hash, and any later compression or capture. A manifest is a pointer to evidence, not the signed chain.
- [ ] Inspect third-party geometry, texture, art, fonts, sound, source photos, provider output terms, likeness, logo, trademark, vehicle trade dress, and required attribution. Record “none found” only after inspection.
- [ ] For generated portraits, bind source PNG and edit lineage to each WebP; verify the source location exists and hash matches. Confirm five device-local player IDs stay recognizable across Fight/Race/Kick and Coaches remain separate.
- [ ] For MakeHuman, inventory exact official core/MPFB/system-pack inputs and licenses; prove restricted community assets did not enter the shipped GLB.
- [ ] For captured media, wait for the [upstream model and scene decisions](runtime-rights-recapture-map.csv); record source revision, every rendered frame input, source video/poster hashes, duration/frames, and sound presence. Recapture dependent media after any changed input. Review unchanged captures only when all recorded inputs are cleared.
- [ ] Sign the [owner attestation](runtime-rights-owner-attestation-template.md), name the chosen disposition and dependent replacement work, then obtain external IP/privacy review of the final exact-file packet. Do not upgrade a ledger row from an unsigned draft.
- [ ] After a replacement/removal, rebuild from an exact branch/commit, regenerate all ledgers and maps, run the affected browser, storage, accessibility, performance, offline, privacy and zero-egress checks, and compare the final package hash. Keep the old source and decision history.
