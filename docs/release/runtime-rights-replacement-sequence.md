The default plan marks all 146 capture rows **recapture/regenerate** because their input chains are still held. This is a scheduling hold, not an instruction to recapture every file unconditionally. If every original input is documented and cleared unchanged, the owner can instead attest to the exact existing video/poster hash. This order avoids reviewing captures whose source models or scenes will be replaced.

For a removal, prove the path has no runtime consumer under default and prototype flags, and keep any visible fallback and accessible naming intact. For a replacement, preserve stable profile IDs, award/vehicle choices, saved progress, and offline loading. Rebuild the package, update its ledger and capture map, and rerun the relevant three-lab, 3D/Canvas, storage, responsive, performance, privacy and zero-egress checks. Stop if a dependent file is still bound to an uncleared source or a new hash lacks a new attestation.
