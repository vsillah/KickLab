## Exceptions requiring evidence outside the repo

1. **Race capture runtime, by three source cohorts:** a dated build/localhost capture receipt, source revision, script invocation, and source-to-MP4/poster derivation proof for each cohort above. If one cohort used multiple runtime trees, split it by actual tree and affected paths. Existing Git media-introduction commits are anchors, not a replacement for that receipt.
2. **Actual frame-visible input findings:** for each genuinely shared Race scene revision and course/venue input set, confirm the GLB, procedural track, lighting, effects, generated imagery, portraits and marks actually seen. For Home, confirm each of the three lab pairs separately, especially the Race car identity and whether any nonprocedural assets appear. Record only deviations by exact path; no 146-row questionnaire is needed.
3. **Owner disposition:** after the above is evidenced, provide a dated, scoped rights finding for unchanged commercial preparation bound to each exact MP4/poster hash and its actual rendered inputs. This is the only decision that cannot be reconstructed from repository bytes. Current H11 hold remains until a separately reviewed ledger/action-map update.

If an input or source chain cannot be supported, the route is a **proposed** bounded recapture with approved inputs or a separately reviewed exclusion and consumer fallback. Neither route is authorized here. The [recapture map](runtime-rights-recapture-map.csv) retains per-path triggers. A shared vehicle change can affect 28 Race files, a Marine or Forest scene 20, and a shared renderer up to 140; these are impact bounds, not recapture orders.

**Validation and stop:** The verifier requires all 146 rows once, all 56 recovered manifest hash bindings, current H11 holds, matching source/package bytes, 73 silent videos, and the known package/web/mobile digests. Stop on any mismatch, unsupported inference, changed media/product byte, or conflicting source-rights fact.
