# Race venue-first preflight contract

This prototype keeps the existing Race flags and local profile storage. A player chooses a venue before its route. Highland offers the five existing Race formats. Marine has two sequential events, Damp Entry and Brake Consistency, on its canonical terrace road. Forest has three sequential events, Descent Entry, Clean Left, and Heat Control, on its canonical descending road. Each event names its own objective and measured thresholds; heat carry makes later braking materially different. A failed attempt retries the current event. The existing `heats` field records the event index, so profile storage remains version 1. Marine and Forest retain the progression unlock order; locked venues stay visible with an explanation. Clearing any solo Highland Race format unlocks Marine. Clearing both Marine events unlocks Forest. Championship and local comparative setup keep their Highland route contracts.

`raceVenue` is a profile-local default. Normalization sends an unknown or no-longer-unlocked venue back to Highland. A draft does not persist until Start heat. The chosen venue then supplies the existing canonical progression geometry, grip, grade, heat, scoring, and results for Marine or Forest. Save & Exit and profile reload restore the saved venue.

The new preview media in `src/media/race-preflight/venue-*.mp4` and `.jpg` was captured locally from the canonical Three.js renderer using `scripts/generate-race-preflight-media.mjs` with `KICKLAB_CAPTURE_VENUES=1`. `venue-manifest.json` and `venue-arrival-manifest.json` retain each venue, vehicle, track key, local asset path, source frame count, duration, bytes, and SHA-256 hashes for the MP4 and poster. `scripts/qa-race-preflight-media.mjs` validates all 40 new files and checks each of the five local model inputs against its asset manifest hash and evaluation-only status. These are renderer captures, not external scenery or third-party stock footage.

Both new media manifests assign every clip and poster a commercial release disposition of **hold: verify capture rights from every rendered input**. The Phase 2 shipped-file ledger predates this branch and must be regenerated for a release candidate; its existing Race capture and model holds still apply. Local capture and matching hashes establish provenance, not commercial clearance. The broader commercial-rights and native-release gates remain held. This change does not authorize store records, distribution, provider activation, or production deployment.
